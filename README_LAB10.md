# Практична робота №10

## Тема: Розгортання Node.js-застосунку за допомогою Docker та Kubernetes

### Мета роботи

Ознайомитися з контейнеризацією Node.js-застосунку за допомогою Docker, навчитися запускати локальний Kubernetes-кластер через Minikube та перевіряти його стан за допомогою kubectl.

### Учасники команди

**Ріта:** локальний запуск Node.js, тестування API, створення Docker-образу, запуск контейнера та налаштування Minikube.

**Юля:** створення Kubernetes-ресурсів Namespace, ConfigMap, Secret, Deployment, Service, перевірка застосунку та налаштування health checks.

## 1. Підготовка проєкту

Створено fork репозиторію `vivalafit/k8s-demo` та клоновано проєкт у папку `D:\k8s-demo`.

Встановлено залежності командою:

`npm install`

## 2. Локальний запуск Node.js

Застосунок запущено командою:

`npm run dev`

Сервер успішно запустився на порту `8080` у режимі `dev`.

### Перевірка API-маршрутів

**1. `/api/status`**

Повертає статус `ok`, режим `dev` та версію застосунку `1.0.0`.

**2. `/api/items?filter=a`**

Повертає список товарів, який містить `Item A`.

**3. `/api/slow`**

Повертає статус `ok` із затримкою 2000 мс.

**4. `/api/error`**

Повертає статус `ok` та повідомлення `No error`.

**5. `/healthz`**

Повертає відповідь `ok`, що підтверджує працездатність застосунку.

**6. `/ready`**

Повертає статус `ready`, що підтверджує готовність застосунку.

**Результат:** усі шість маршрутів успішно перевірено.

## 3. Робота з Docker

Створено Docker-образ командою:

`docker build -t k8s-demo-app:1.0.0 .`

Запущено контейнер командою:

`docker run --rm -p 8080:8080 -e SECRET_TOKEN=local k8s-demo-app:1.0.0`

Перевірено роботу API через команди:

`curl.exe http://localhost:8080/api/status`

`curl.exe http://localhost:8080/healthz`

**Результат:** Docker-образ успішно створено, контейнер запущено, застосунок відповідає на HTTP-запити.

## 4. Запуск Kubernetes через Minikube

Для створення локального Kubernetes-кластера використано команду:

`minikube start --memory=4096 --cpus=2 --driver=docker`

Перевірено стан вузла командою:

`kubectl get nodes`

Отримано такі результати:

- Назва вузла: `minikube`.
- Статус вузла: `Ready`.
- Версія Kubernetes: `v1.37.0`.

Перевірено системні поди командою:

`kubectl get pods -A`

Отримано такі результати:

- Кількість системних подів: 8.
- Статус усіх подів: `Running`.
- Готовність усіх подів: `1/1`.
- Кількість перезапусків: 0.

**Результат:** локальний Kubernetes-кластер успішно запущено та перевірено його працездатність.

## 5. Налаштування Kubernetes-ресурсів
